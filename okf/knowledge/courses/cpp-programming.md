# C++ Programming

## Course Overview

C++ Programming is an offline classroom course that develops
programming skills through C++ fundamentals, Object-Oriented Programming,
memory management, templates, the Standard Template Library,
exception handling and file handling.

The course progresses from core C++ concepts into reusable and
object-oriented software design.

## Course Format

- Offline, in-person classes
- Beginner friendly
- Live coding
- Whiteboard teaching
- Hands-on practice
- Assignments
- Coding tests
- Project checkpoints

## Who Is It For?

- Absolute beginners
- Students learning C++
- Aspiring developers
- Learners strengthening programming fundamentals

## Learning Objectives

The course focuses on:

- C++ programming fundamentals
- Object-Oriented Programming
- Memory management
- Object lifetime
- Generic programming
- STL containers
- Exception handling
- File input/output
- Problem solving
- Practical programming
