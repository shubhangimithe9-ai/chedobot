# C + C++ + DSA

## Course Overview

C + C++ + DSA is an offline classroom foundation course that combines
C programming, C++ Object-Oriented Programming, the C++ Standard Template
Library, Data Structures and Algorithms.

The course is designed to build programming logic and problem-solving
skills before moving toward advanced software development.

## Course Format

- Offline classroom training
- Pune
- Beginner friendly
- Hands-on coding practice
- Whiteboard teaching
- Live coding
- Project-based learning
- Technical interview preparation

## Target Audience

- Aspiring developers
- Engineering students
- Beginners learning programming
- Students building strong programming fundamentals
- Learners preparing for technical interviews

## Learning Journey

1. Zero Programming
2. C Language
3. C++ Object-Oriented Programming
4. C++ Standard Template Library
5. Data Structures Foundation
6. Algorithms
7. Graphs and Advanced Dynamic Programming
8. Interview Preparation
