# Java Programming

## Course Overview

Java Programming is an offline classroom course designed to build strong
Java programming foundations and Object-Oriented Programming skills.

The course progresses from Java syntax and control flow into methods,
constructors, inheritance, abstraction, polymorphism, interfaces,
exception handling, GUI programming, file handling and algorithms.

## Course Format

- Offline, in-person classes
- Beginner friendly
- Live coding
- Whiteboard teaching
- Hands-on practice
- Assignments
- Coding tests
- Project checkpoints

## Who Is It For?

- Absolute beginners
- Students learning Java
- Aspiring developers
- Learners building programming fundamentals
