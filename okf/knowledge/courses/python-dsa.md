# Python + DSA

## Course Overview

Python + DSA is an offline classroom course focused on Python programming,
Data Structures, Algorithms, coding patterns and technical interview
problem solving.

The course uses Python's clean syntax and built-in collections to develop
strong programming logic and efficient problem-solving skills.

## Course Format

- Offline classroom learning
- Pune
- Beginner friendly
- Hands-on coding practice
- Coding problem solving
- Technical interview preparation

## Course Objective

The course focuses on building strong Python programming skills and using
Python to solve Data Structures and Algorithms problems efficiently.

The course focuses on pure Python logic and DSA. It does not focus on
Data Science, Django or Machine Learning.

## Practical Projects

### Linked Lists and Stacks

Students implement manual node classes, linked lists,
insertions, deletions, reversals, middle-element detection
and stack structures.

### BST and Heap Priority Filters

Students implement Binary Search Trees, tree operations,
heap operations and Top-K filtering using Python heapq.

### Graph Route and Path Finder

Students create an algorithmic pathfinder using Python
dictionary-based adjacency maps, BFS, DFS, cycle detection
and shortest-path algorithms.
