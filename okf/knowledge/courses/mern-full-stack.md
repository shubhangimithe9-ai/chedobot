# MERN Full Stack Development

## Course Overview

MERN Full Stack Development is a full-stack web engineering program
covering modern JavaScript development from frontend interfaces to
backend APIs, databases, security, deployment and AI integration.

The program uses React, Node.js, Express and MongoDB as core
technologies.

## Program Format

- Offline, in-person training in Pune
- Full Stack JavaScript learning path
- Daily batches
- Practical projects
- Full-stack capstone

## Prerequisites

No prior coding experience is required.
