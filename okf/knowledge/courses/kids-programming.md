# Kids Programming

## Course Overview

Kids Programming introduces children to programming and computational
thinking through beginner-friendly coding concepts and practical
problem-solving activities.

The course focuses on developing logical thinking, creativity and
confidence with programming.

## Learning Objectives

Students learn to:

- Understand basic programming concepts
- Develop logical thinking
- Break problems into smaller steps
- Understand algorithms
- Use programming constructs
- Build simple programs
- Solve problems through coding
- Develop computational thinking

## Curriculum

### Module 1 — Introduction to Programming

- What is programming?
- What is a computer program?
- Programming languages
- Algorithms
- Step-by-step problem solving
- Computational thinking

### Module 2 — Programming Fundamentals

- Variables
- Data types
- Values
- Input and output
- Basic operators

### Module 3 — Conditions

- Decision making
- If statements
- If-else statements
- Multiple conditions
- Logical operators

### Module 4 — Loops

- Repetition
- For loops
- While loops
- Nested loops
- Pattern-based problems

### Module 5 — Functions

- What is a function?
- Creating functions
- Parameters
- Return values
- Reusable code

### Module 6 — Problem Solving

- Breaking problems into steps
- Identifying patterns
- Algorithm development
- Debugging
- Logical reasoning
- Problem-solving exercises

### Module 7 — Beginner Projects

Students apply programming concepts through simple projects.

Possible projects include:

- Number guessing activity
- Calculator
- Quiz application
- Pattern programs
- Simple games
- Interactive coding activities

## Learning Approach
