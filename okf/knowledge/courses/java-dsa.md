# Java + DSA

## Course Overview

Java + DSA is an offline classroom course focused on Java programming,
Object-Oriented Programming, the Java Collections Framework,
Data Structures, Algorithms, problem solving and coding practice.

The course focuses on Core Java, Collections and DSA rather than
enterprise frameworks.

## Course Format

- Offline classroom training
- Live whiteboard coding
- Hands-on coding practice

## Who Is It For?

- Students
- Developers
- Learners preparing for MNC coding tests
- Learners who want to strengthen Java and DSA fundamentals

## Technologies

- Java
- Java OOP
- Java Collections Framework
- Data Structures
- Algorithms

## Learning Path

1. Java Fundamentals
2. Logic Building
3. Object-Oriented Programming
4. Advanced Java
5. Collections Framework
6. Complexity Analysis
7. Data Structures

## Practical Projects

### Linked Lists and Deques

Students implement linked-list structures manually,
including node creation, insertion, deletion and reversal.

### BST and Heap Priority Queues

Students implement binary search trees, traversals,
heap operations and priority queues.

### Algorithmic Router Console

A larger implementation combining Java OOP, custom data structures,
graphs, traversal algorithms and exception handling.
