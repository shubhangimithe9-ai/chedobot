# Python Programming

## Course Overview

Python Programming is an offline classroom course designed to build
strong programming fundamentals and practical Python development skills.

The course progresses from Python basics and logic building into
functions, collections, Object-Oriented Programming, modules,
exception handling and file handling.

## Course Format

- Offline, in-person classes
- Beginner friendly
- Live coding
- Whiteboard teaching
- Hands-on practice
- Assignments
- Coding tests
- Project checkpoints

- Absolute beginners
- Students learning Python
- Aspiring developers
- Learners building programming fundamentals
- Students preparing for further Python-based technologies
