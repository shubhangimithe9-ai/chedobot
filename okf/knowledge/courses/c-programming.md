# C Programming

## Course Overview

C Programming is an offline classroom course designed to build strong
programming fundamentals, logic-building and problem-solving skills.

The course starts from absolute programming basics and progresses through
control flow, arrays, strings, pointers, memory management, functions,
recursion, structures and file handling.

## Course Format

- Offline, in-person classes
- Beginner friendly
- Live coding
- Whiteboard teaching
- Hands-on practice
- Assignments
- Coding tests
- Project checkpoints

## Who Is It For?

- Absolute beginners
- Students learning programming
- Aspiring developers
- Learners who want strong programming fundamentals

No prior coding knowledge is required.

## Learning Objectives

The course helps learners develop:

- Programming fundamentals
- Strong logic-building skills
- Problem-solving ability
- Memory understanding
- Pointer understanding
- Debugging skills
- Structured programming skills
- Practical coding experience
