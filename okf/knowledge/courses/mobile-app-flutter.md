# Mobile App Development (Flutter)

## Course Overview

Mobile App Development with Flutter focuses on building cross-platform
mobile applications using Flutter and Dart.

The course covers programming fundamentals, Flutter widgets, user
interfaces, navigation, application state, API integration, data
storage and mobile application development.

## Technologies

- Dart
- Flutter
- Android
- iOS
- REST APIs
- JSON
- Firebase
- Git and GitHub

## Learning Objectives

Students learn to:

- Understand Dart programming
- Build Flutter user interfaces
- Work with widgets
- Create multi-screen applications
- Navigate between screens
- Manage application state
- Connect applications to APIs
- Store application data
- Build and test mobile applications
