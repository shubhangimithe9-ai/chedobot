# Chedo Tech Learning

## Learning Approach

Chedo Tech provides structured learning programs covering
programming, software development, data science, artificial
intelligence, mobile development and design.

## Programming Practice

Programming-focused courses cover concepts through structured
learning and problem-solving practice.

Topics may include:

- Programming fundamentals
- Object-oriented programming
- Data structures
- Algorithms
- Problem solving
- Coding practice

## Practical Learning

Several programs include practical development and project-based
learning.

Projects can help students apply concepts to software,
web, mobile, data and AI applications.

## Technology Areas

The learning programs cover areas including:

- C
- C++
- Java
- Python
- Data Structures and Algorithms
- Web Development
- Full Stack Development
- Flutter
- Data Science
- Machine Learning
- Generative AI
- UI/UX Design

## Choosing a Course

Course selection depends on the learner's existing knowledge,
learning goals and the technology area they want to study.

The chatbot should use the specific course information available
in the knowledge base when answering course-related questions.

## Information Availability

The chatbot should not invent course duration, fees, batches,
placements, certifications or other details when those details are
not available in the knowledge base.
