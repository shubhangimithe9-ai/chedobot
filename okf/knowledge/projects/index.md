# Chedo Tech Projects

## Overview

Projects are used as a practical way to apply programming and
technology concepts learned during Chedo Tech programs.

## Project Areas

Projects may relate to different technology areas covered by
Chedo Tech courses, including:

- Programming
- Data Structures and Algorithms
- Web Development
- Full Stack Development
- Mobile App Development
- Data Science
- Machine Learning
- Generative AI
- UI/UX Design

## Programming Projects

Programming projects can be used to practice:

- Programming fundamentals
- Object-oriented programming
- Data structures
- Algorithms
- Problem solving

## Web Development Projects

Web development projects can involve:

- Frontend development
- Backend development
- Databases
- APIs
- Full-stack application development

## Mobile Development Projects

Mobile development projects can involve:

- Flutter
- Dart
- User interfaces
- Navigation
- APIs
- Application data

## Data and AI Projects

Data and AI projects can involve:

- Data analysis
- Data visualization
- Machine learning
- Natural language processing
- Generative AI
- AI applications

## Project Information Policy

The chatbot should provide only project details available in the
Chedo Tech knowledge base.

If a specific project name or project detail is not available,
the chatbot should not invent one.
