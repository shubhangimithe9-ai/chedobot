# Chedo Tech Frequently Asked Questions

## What courses does Chedo Tech offer?

Chedo Tech offers courses and programs including:

- Java + DSA
- Python + DSA
- C + C++ + DSA
- C Programming
- C++ Programming
- Java Programming
- Python Programming
- Data Structures & Algorithms
- MERN Stack Web Development
- Java Full Stack Development
- Mobile App Development (Flutter)
- Data Science Foundation
- Data Science, Machine Learning & Generative AI
- UI/UX Design
- Kids Programming

## Does Chedo Tech teach programming?

Yes. Its course offerings include programming courses such as C,
C++, Java and Python, as well as combined programming and DSA
programs.

## Does Chedo Tech teach Data Structures and Algorithms?

Yes. Data Structures and Algorithms is offered as a dedicated
course and is also included in programs such as Java + DSA,
Python + DSA and C + C++ + DSA.

## Does Chedo Tech offer full-stack development courses?

Yes. The course offerings include MERN Stack Web Development and
Java Full Stack Development.

## Does Chedo Tech offer mobile app development?

Yes. Chedo Tech offers Mobile App Development using Flutter.

## Does Chedo Tech offer Data Science and AI courses?

Yes. The course offerings include Data Science Foundation and
Data Science, Machine Learning & Generative AI.

## Does Chedo Tech offer UI/UX Design?

Yes. UI/UX Design is one of the listed programs.

## Does Chedo Tech offer programming for children?

Yes. Kids Programming is one of the listed programs.

## What should I do if information is not available?
